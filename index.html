Capabilities

Everything in one external overlay

Six core modules, each documented and open for inspection in the repository.

🎯

Bone-Level Snaplines

Draws precise lines to head, chest, and pelvis bones using live skeleton data — a clean visual reference for hitbox research.

👁️

External ESP

Overlay boxes, health bars, and distance tags rendered outside the process, so nothing is injected into the game client.

🧭

Overlay Radar

A compact top-down radar showing nearby players and orientation, useful for studying spatial awareness and map flow.

🛡️

No-Recoil Module

Analyzes recoil patterns frame-by-frame to illustrate spray control mechanics and weapon behavior in a controlled sandbox.

⚙️

Injector Loader

A minimal standalone loader that attaches the overlay safely for testing, with clear logs and a single-click detach.

🧪

Educational Sandbox

Commented source, module breakdowns, and safe defaults — designed to teach how external overlays and memory reads work.

Setup

Up and running in three steps

No installers, no background services — just a portable folder you control.

1

Download the release

Grab the latest build from gitscore.cc, then unzip the portable folder anywhere on your Windows 10 or 11 machine.

2

Run the injector loader

Launch the loader as administrator and select the overlay module. The console window prints a step-by-step attach log.

3

Configure the overlay

Open the in-overlay menu to toggle ESP, radar, snaplines, and recoil modules. Use practice modes only — never in live matches.
